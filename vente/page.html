Courriels

Les envois de courriels, trouvés puis remplacés

Relances, alertes, rapports du lundi : les macros qui envoient des courriels cassent deux fois. Le SMTP par mot de passe tombe fin décembre 2026, l'automatisation d'Outlook en mars 2027. Passer de l'un à l'autre ne règle rien.

  • Repérés partoutOutlook, DoCmd.SendObject, MAPI, CDO et SMTP, dans les macros, les applications VB6, les outils .NET et leurs fichiers de configuration.
  • Un module libre pour les remplacerModGraphMail.bas, sous licence MIT, fourni avec l'outil : une ligne EnvoyerCourriel à la place d'Outlook ou de CDO, en VBA et en VB6, Office 32 et 64 bits, sans DLL.
  • Une seule boîte autoriséeMicrosoft Graph, avec un droit d'envoi limité à une boîte par Exchange Online. Le secret reste dans le Gestionnaire d'identification Windows, jamais dans le code.
  • Le guide de l'administrateurSix étapes et 20 minutes dans Entra ID et Exchange Online, commandes PowerShell comprises. Lire l'article sur les deux échéances.

Comment ça se passe

Diagnostic : vous lancez l'outil avec --diagnostic et vous envoyez diagnostic.json. Remédiation : vous envoyez une copie des fichiers concernés et vous recevez les fichiers corrigés. Aucun accès à vos systèmes, aucun déplacement.

Délai garanti

Compté à partir de la réception du fichier. S'il n'est pas tenu, la formule est remboursée en entier et le rapport vous reste.

Ce qui n'est pas inclus

La correction des macros au-delà de l'envoi de courriels, et les outils .NET. Un projet VB6 corrigé est livré en sources, à recompiler chez vous. Le diagnostic ne modifie jamais vos fichiers.

Questions

Questions fréquentes

Une autre question avant de commander ? L'adresse de contact figure sur la page de commande.

L'outil peut-il abîmer nos fichiers ?

Non. Il ouvre chaque fichier en lecture, le décode en mémoire et le referme. Il ne l'ouvre jamais dans Office, ne change ni son contenu ni sa date. Les fichiers verrouillés ou protégés sont signalés, pas forcés.

Et les projets protégés par mot de passe ?

Le mot de passe VBA protège l'affichage dans l'éditeur, pas le stockage : le code est lu et analysé quand même, et le fichier est signalé comme protégé. Les fichiers chiffrés à l'ouverture sont listés à part.

Et les bases Access ?

Leur code est stocké dans un format interne non documenté. Un script PowerShell fourni l'exporte depuis une copie de chaque base, macros désactivées, puis l'outil analyse l'export. L'original n'est jamais ouvert.

Et les applications VB6 et .NET ?

L'outil lit les projets .vbp et leurs sources : composants OCX hors support, VBScript, Outlook, accès au matériel. Pour .NET, il cherche les envois de courriels et les mots de passe SMTP dans le code et les fichiers .config, sans analyser le reste.

Faut-il installer quelque chose ?

Non avec le zip : un exécutable autonome, sans Node.js ni Python, sans droits d'administrateur. Le MSI installe dans Program Files pour un déploiement par GPO, Intune ou SCCM. L'exécutable n'est pas encore signé : Windows SmartScreen peut demander une confirmation.

Les estimations sont-elles fiables ?

Ce sont des ordres de grandeur, calculés avec des coefficients publiés dans la documentation, pour un développeur VBA expérimenté. Le diagnostic Complet les ajuste fichier par fichier.

Et si un fichier est malveillant ?

Les motifs classiques (téléchargement et exécution à l'ouverture) sont signalés en priorité et sortis de l'estimation : on isole un tel fichier, on ne le corrige pas. L'outil ne remplace pas un antivirus.

Comment se passe la facturation ?

Paiement par carte à la commande. Le reçu fait office de facture et peut porter votre raison sociale et votre numéro de TVA. Paiement par virement sur bon de commande : sur demande écrite.

Corrigez-vous les macros ensuite ?

Pour l'envoi de courriels, oui : c'est la remédiation à prix fixe. Pour le reste, le plan d'action est écrit pour que votre équipe ou votre prestataire habituel le suive. Rien ne demande de déplacement ni de formation.
