# Revue du diagnostic — modèle

Recopiez ce fichier, remplissez les trois sections, puis :
inventaire-vba --depuis diagnostic.json --revue revue.md --organisation "Client" --date AAAA-MM-JJ --pdf -o livraison

Seules les sections qui commencent par « ## » sont reprises dans le rapport.

## Synthèse

Trois à six phrases pour un décideur : combien de fichiers cassent, à quelle échéance, ce qu'il faut faire d'abord et le budget en jours. Citez les chiffres du rapport.

## Remarques par constat

- B64-001 : remarque d'expert sur cette règle pour ce parc (priorité, piège, regroupement).
- SIG-001 : …
